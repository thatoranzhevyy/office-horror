# AFTER HOURS — Multiplayer Office Horror

Рабочая тестовая версия 0.1.0. Браузерная 3D PvP-игра на Vue 3, Three.js, TypeScript, Node.js, WebSocket и Rapier.

## Деплой

Для одного сервиса с сайтом и WebSocket используйте [инструкцию Render](RENDER.md) и Blueprint [render.yaml](render.yaml).

## Быстрый запуск

Требуется **Node.js 22.12+ или 24 LTS** и npm. Распакуйте архив в обычную папку, откройте терминал **внутри `office-horror`**:

```bash
npm ci
npm start
```

Откройте **http://localhost:3001**. Папка `dist` уже включена: для первого теста сборка не нужна. Интернет нужен при первой установке npm-пакетов; во время игры CDN и внешние сервисы не используются.

Если изменили исходники клиента:

```bash
npm run build
npm start
```

Для разработки с перезапуском:

```bash
npm run dev
```

Открывать http://localhost:5173. Vite проксирует `/ws` на игровой сервер 3001.

## Реальный сетевой тест

1. На одном компьютере запустите сервер командой выше.
2. Откройте игру в двух окнах/браузерах. Укажите **одинаковый код комнаты**, например `NIGHT01`.
3. Выберите ALPHA в одном окне, BRAVO в другом, войдите.
4. Нажмите **«Я готов»** в обоих окнах. Минимум — один игрок с каждой стороны; заполнять все места не требуется.
5. Для другого компьютера в одной Wi-Fi/LAN сети откройте `http://IP-СЕРВЕРА:3001`. Разрешите входящие подключения Node/порта 3001 в локальном firewall. `localhost` на втором компьютере обозначает его самого, поэтому ссылку с localhost отправлять нельзя.
6. Для одиночной проверки войдите в пустую комнату и нажмите **«Тренировка с ботом»**. Бот явно обозначен в лобби и управляется сервером; это дополнительный режим, не имитация мультиплеера.

Игровой экран рассчитан на компьютер, клавиатуру и мышь. На телефоне можно посмотреть лобби, но сенсорное управление персонажем в эту версию не входит.

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D | Движение относительно экрана |
| Shift | Бег, более частые слышимые шаги |
| Мышь | Прицел и фонарь |
| ЛКМ / удержание | Выстрел / последовательные выстрелы |
| 1 | Бросить химический свет вперёд (до 6 м): освещает радиус 8 м на 18 с; откат 24 с |
| 2 | Банановая кожура; откат 12 с, взведение 0,8 с |
| 3 | Пистолет (в этой сборке всегда доступен) |
| R | Перезарядка, 1,7 с |
| M | Включить/выключить звук |

Кожура действует на любого игрока после взведения, включая владельца. Скольжение длится 1,5 с, стрельба и способности временно блокируются. Дружественный огонь не наносит урон, но союзник останавливает луч пули. Магазин 12 патронов, резерв перезарядки не ограничен. Урон пистолета 25, здоровье 100. При потере фокуса кнопки движения/огня сбрасываются.

Камера — перспективная, с плавным следованием, упреждением взгляда и задержкой поворота. Новый курс фиксируется при осознанном движении мыши/начале движения, чтобы вращение камеры само не закручивало прицел. Стрельба даёт пружинную отдачу; попадания — короткую тряску.

## Правила матча

По умолчанию до 2 игроков в каждой команде. Побеждает последняя живая команда. Возрождения внутри раунда нет. Через 5 минут сравниваются число выживших, затем суммарное HP. При равенстве — ничья. После завершения снова нажмите готовность. Офис сохраняет seed комнаты между раундами; ловушки, HP и способности сбрасываются. Пустые комнаты удаляются; новый код создаёт новый офис.

Комнаты не защищены паролями: код комнаты — способ объединить участников теста. Лобби не допускает подключение нового игрока в середине матча. После разрыва соединения автоматического восстановления участия в текущем раунде нет.

## Настройки сервера

macOS/Linux:

```bash
TEAM_SIZE=4 PORT=3001 npm start
```

PowerShell:

```powershell
$env:TEAM_SIZE="4"
$env:PORT="3001"
npm start
```

`TEAM_SIZE`: 1–8, по умолчанию 2. `PORT`: по умолчанию 3001. При смене порта в dev-режиме измените target в `vite.config.ts`.

## Docker

```bash
docker compose up --build
```

Открыть http://localhost:3001. Для другого размера команды измените `TEAM_SIZE` в `compose.yaml`.

## Что работает

- Настоящие WebSocket-комнаты, команды, два внешних вида персонажа, готовность, старт и результат раунда.
- Серверная симуляция 30 Гц: ввод с порядковыми номерами, положение, столкновения, выстрелы, урон, боезапас, откаты и ловушки.
- Клиентское предсказание с подтверждениями/reconciliation, интерполяция соперников. Сервер не принимает координаты от клиента.
- Rapier capsule character controller: разгон, торможение и скольжение вдоль стен; игроки не толкают друг друга.
- Seed-зависимый квадратный лабиринт с закрытыми границами: 64×64 м для 2–4 игроков, 128×128 м для 5–10 и 192×192 м для 11–16. Размер фиксируется при старте раунда.
- Рекурсивный обход, дополнительные петли, расширения под комнаты, 12 room presets и согласованные порталы между чанками.
- Чанки 32×32 по 2 м, загрузка/выгрузка окружения и физических препятствий вокруг участников. Ловушки и свет хранятся отдельно от графики.
- InstancedMesh и общие геометрии/материалы для повторяющихся объектов, frustum/chunk culling.
- Тёплый фонарь, тени, raycast-маска, ограниченная карта исследованной территории. Невидимые персонажи не передаются как акторы.
- Отдельные световые пятна чужого фонаря: можно заметить свет без получения модели его владельца.
- Hitscan с блокировкой стенами/мебелью, разбросом от скорости, вспышками и короткими трассерами.
- Бросаемый химический свет, остающийся на полу, банановая ловушка, HP, смерть, перезарядка.
- Синтезированные пространственные звуки выстрелов, шагов, скольжения и электричества; тихий фон вентиляции.
- Минимальный HUD по референсу, лобби и приглашение ссылкой.

## Границы тестовой версии относительно полного ТЗ

Это первая игровая сборка для проверки механик, а не утверждение о готовности всех 34 пунктов к промышленному запуску.

- Low-poly модели генерируются кодом. Есть столы, переговорные столы, стулья, reception, шкафы, полки, диваны, растения, кулеры, серверы, принтеры, кофемашины, холодильники, коробки, бумага и предупреждающие таблички. Мониторы, клавиатуры и системные блоки входят в модели столов. Полный художественный каталог всех перечисленных в исходном ТЗ предметов ещё не воспроизведён.
- Комнаты — расширенные области лабиринта с тематическими наборами, без сложной архитектурной семантики. Интерактивных закрывающихся дверей пока нет; LOS сейчас блокируют стены и крупные непрозрачные объекты.
- Нет редактора карты, учётных записей, рейтинга, сохранения матчей, matchmaking, голосового чата и production-античита.
- Звуки процедурные, без готовых записей принтера, дыхания и heartbeat. Нет полноценного volumetric-конуса фонаря, постоянных bullet decals, ragdoll и импортированных анимаций.
- Видимые персонажи интерполируются; появление из-за угла ограничивается серверным LOS и маской. Исторический server rewind/lag compensation не реализован.
- Для производительности работают инстансинг и streaming. Отдельных mesh LOD и универсального object pool пока нет. Производительность 60 FPS на всех устройствах не гарантирована; нагрузочный тест 16 игроков и длительного бесконечного матча не проводился.
- Бот тренировочный: исследует ближайшие коридоры, стреляет только при LOS. Он не заменяет тест с реальным противником.

## Проверки

```bash
npm test
npm run build
```

Сетевой тест требует запущенного сервера в другом терминале:

```bash
NETWORK_TEST=1 npm test
```

В PowerShell: `$env:NETWORK_TEST="1"; npm test`. Для другого адреса используйте `TEST_URL=ws://HOST:PORT/ws`.

Без `NETWORK_TEST=1` сетевой тест явно пропускается. Проверяются seed, связность, границы отрицательных чанков, LOS, raycast, capsule sliding, валидация/флуд ввода, урон/откаты, ловушки, результат раунда, безопасные спавны, фильтрация событий, задержка камеры и короткий клик между тиками.

Предыдущая проверка реального WebSocket-матча и Chromium/WebGL записана в `docs/verification.md`. Она проводилась до изменения карты и первой способности.

## Структура

- `shared/map.ts` — генерация и чанки.
- `shared/visibility.ts` — raycast, LOS, polygon.
- `shared/physics.ts` — Rapier и общая интеграция движения.
- `shared/protocol.ts` — сетевые типы.
- `server/game.ts` — авторитетная логика раунда.
- `server/index.ts` — WebSocket, комнаты, HTTP, лимиты сообщений.
- `src/engine.ts` — сцена, камера, предсказание, маска, minimap.
- `src/models.ts` — low-poly модели/инстансинг.
- `src/audio.ts` — Web Audio.
- `src/App.vue` и `src/style.css` — лобби и HUD.
- `tests/` — тесты, включая opt-in сетевой.

Не открывайте `index.html` двойным кликом: браузеру нужен HTTP/WebSocket-сервер.
